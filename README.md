# AionGraphos

A work-in-progress Android astrology engine written in Kotlin.

## Features

- Swiss Ephemeris integration
- Planetary position calculations
- House system calculations
- Aspect detection
- Arabic Lots calculation
- Domain-driven architecture
- Essential and accidental dignities

## Planned Features

- Geolocation support
- Jetpack Compose UI
- Chart rendering

## Tech Stack

- Kotlin
- Jetpack Compose
- Swiss Ephemeris (Java)
- Android SDK

## Status

Work in progress.
